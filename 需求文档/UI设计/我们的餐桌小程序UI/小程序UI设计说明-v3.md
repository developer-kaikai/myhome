### 2.1 色彩使用比例

- 奶油底色和暖白卡片约占页面 75%。
- 深可可文字约占 15%。
- 陶土红、杏桃、黄油黄及状态绿合计控制在 10% 左右。
- 每个页面最多一个大面积陶土红实心按钮，避免再次出现“所有模块都抢眼”的问题。

## 3. 字体方案

### 3.1 字体家族

| 内容 | 推荐字体 | 回退方案 |
| --- | --- | --- |
| 情绪化页面标题 | 思源宋体 CN / Noto Serif SC SemiBold | `Songti SC`, `STSong`, serif |
| 模块标题、正文、按钮 | 思源黑体 CN / Noto Sans SC | `PingFang SC`, `Microsoft YaHei`, sans-serif |
| 数字、评分、数量 | 与正文同族，使用等宽数字特性 | 系统无衬线字体 |

如果首版不希望引入网络字体，iOS 与 Android 的宋体表现可能不同。开发时可将首页、选择餐厅、评价、聚会等少量一级标题打包为经过授权的字体子集；正文始终使用系统黑体，保证加载速度和可读性。

### 3.2 字级与排版

| 层级 | 建议值 | 规则 |
| --- | --- | --- |
| 页面情绪标题 | 30—32px / 1.18 / 600 | 使用宋体，只用于每页首个主标题 |
| 页面功能标题 | 24—26px / 1.25 / 600 | 宋体或黑体，根据页面情绪程度选择 |
| 模块标题 | 18—20px / 1.35 / 600 | 黑体，避免过粗 |
| 正文 | 14—16px / 1.55 / 400 | 黑体，长文本不使用宋体 |
| 辅助信息 | 12—13px / 1.45 / 400 | 使用次文字色，不低于 12px |
| 主按钮 | 16px / 1 / 600 | 黑体，字间距 `0.02em` |
| 关键数字 | 24—30px / 1 / 600 | 使用等宽数字，单位字号缩小一级 |

标题的字间距建议为 `0.01em`，正文为 `0`，短标签可使用 `0.02em`。不要通过连续空格制造字距。

## 4. 组件更新

- **主按钮**：陶土红底、暖白字，高度 48—52px；按下时颜色加深约 8%。
- **次按钮**：暖白底、陶土红 1px 描边；同一行最多两个。
- **选中标签**：杏桃色或浅陶土底，使用深可可文字，避免白字小标签影响阅读。
- **状态标签**：成功使用灰橄榄绿，待确认和补充中使用黄油黄；必须同时显示状态文字。
- **卡片**：暖白背景、18—20px 圆角、1px 浅分割线或极轻阴影，二者择一。
- **底部导航**：当前项使用陶土红；其余为深可可色的 55% 透明度。
- **星级评分**：保留暖金色，避免与陶土红竞争。

## 5. 页面应用规则

- 首页、选择餐厅、评价页和聚会标题使用宋体，增强生活感和情绪记忆。
- 点餐列表、订单明细、采购清单和主厨工作台以黑体为主，保证高密度信息可扫读。
- 菜品详情的大图继续承担主要吸引力，陶土红只用于“加入清单”。
- “确认这顿饭”使用黄油黄标记“仅主厨可见”，主操作使用陶土红，未勾选项保持中性灰。
- 聚会重开的“补充中”与说明条使用黄油黄，“补报名”和“分享邀请”使用描边按钮。
- 日常点餐仍不得出现价格、支付、购物车、配送、优惠券或商业促销表达。

本版使用内置 ImageGen 的 `ui-mockup` 编辑模式，在保留 v2 页面结构、文案、图片和业务功能的前提下，只调整色彩、字体与组件层级：

> 将“我们的餐桌”从鼠尾草绿色调改为奶油纸张、陶土红、杏桃和深可可色。情绪化一级标题使用现代中文宋体，导航、按钮、正文、数字使用思源黑体风格；加强标题、模块、正文、元数据层级。主按钮使用陶土红，选中标签使用杏桃色，小面积成功状态保留灰橄榄绿，提示使用黄油黄。保持十二个页面结构和全部业务约束不变，不增加价格、支付、配送、购物车、接单按钮或商业促销元素。
